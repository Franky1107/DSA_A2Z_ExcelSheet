# Striver A2Z DSA — LeetCode Tracker

An Excel workbook for working through [Striver's A2Z DSA Sheet](https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet?open=none) on LeetCode and tracking progress problem by problem.

📥 **[Striver_A2Z_DSA_LeetCode_Tracker.xlsx](./Striver_A2Z_DSA_LeetCode_Tracker.xlsx)** (open it in Excel, LibreOffice, or Google Sheets)

## What's inside

- **474 problems** across **18 topics**, kept in the original A2Z order
- **152 Easy, 186 Medium, 136 Hard**
- A **LeetCode link for each problem**:
  - 249 link directly to the matching LeetCode problem (or a close equivalent)
  - 225 open a LeetCode title search, for problems with no exact LeetCode match
- A **Status dropdown** on every row: `Not Started` · `In Progress` · `Solved` · `Need Revision`
- A **Notes** column for your approach, complexity, or edge cases

## Sheets

| Sheet | Purpose |
|---|---|
| **Dashboard** | Totals for solved and remaining problems, updated by formulas |
| **All Questions** | The full list of problems. Update your status here |
| **Easy / Medium / Hard** | The same problems split by difficulty |
| **Topic Summary** | Total, Easy, Medium, Hard, Solved, and Remaining counts for each topic |
| **Current Official Overview** | Module counts from the current official takeUforward sheet |
| **Read Me** | Notes on the data, how the links work, and sources |

## How to use

1. Download the workbook.
2. Work through the **All Questions** sheet in order and open each problem from its LeetCode URL.
3. When you finish a problem, set its **Status** to `Solved`. Use `Need Revision` for problems you want to come back to.
4. The **Dashboard** and **Topic Summary** sheets update on their own.
